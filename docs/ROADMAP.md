# Alexander OS — Delivery Roadmap

## Stage 0 — Product and design approval
- [ ] Review all documentation and resolve architecture questions.
- [ ] Build a high-fidelity clickable UI prototype with labeled demo data.
- [ ] Review desktop and mobile; confirm design system and interaction model.

## Stage 1 — Foundation
- [ ] Scaffold app, formatting, type checking, tests, and CI.
- [ ] Authentication and database setup.
- [ ] Home shell and global navigation.
- [ ] Tasks, projects, notes, quick capture.

## Stage 2 — Interest Intelligence MVP
- [ ] Interest preferences and source registry.
- [ ] RSS ingestion with retry and idempotency.
- [ ] Article canonicalization and exact deduplication.
- [ ] Event clustering and relevance ranking.
- [ ] Source-grounded manual briefing.
- [ ] Scheduled daily/weekly briefings and delivery history.

## Stage 3 — Personal Library
- [ ] Book/game/movie catalog search and metadata adapters.
- [ ] Ownership, backlog, progress, ratings, notes.
- [ ] Collection UI and detail pages.

## Stage 4 — Assistant
- [ ] Chat, scoped read tools, cited responses.
- [ ] Proposed actions with confirmation.
- [ ] Conversation history, context policy, audit.

## Stage 5 — Integrations and proactive operation
- [ ] Calendar read sync and schedule summaries.
- [ ] Gmail read sync and priority email triage.
- [ ] Notifications, quiet hours, failure handling.
- [ ] Fitness/nutrition integration and advanced personalization.

## Milestone completion rule
Only mark complete when demonstrated, tested, and documented. Track open bugs and known limitations in the relevant module specification.
