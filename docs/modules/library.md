# Personal Library — Feature Specification

Support BOOK, GAME, MOVIE initially. User can search catalog providers, add to collection, mark owned/wishlist, backlog/in-progress/completed, rate, record progress and notes, and filter/sort. Show cover art and metadata with attribution as required. Do not conflate owning with completing. Provide manual entry if an API has no match. External metadata adapters must be swappable; avoid assuming access to a paid API. Use meaningful empty states and immersive shelves/cover layouts per DESIGN_SYSTEM.md.
