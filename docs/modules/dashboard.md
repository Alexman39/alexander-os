# Home Dashboard — Feature Specification

Desktop home includes ambient identity header, navigation, featured briefing, live module tiles, today's schedule, focus tasks, progress, interest feed, and assistant entry point. All widgets support real data, loading, empty, error, and explicit demo states. Tile sizes and arrangements are deliberate and asymmetric. User can reach every major module with keyboard and touch. Mobile should retain information priority without shrinking desktop UI. Refer to DESIGN_SYSTEM.md for aesthetic approval criteria.
