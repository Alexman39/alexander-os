# Getting Started with Claude Code

1. Create a Git repository and copy this folder's contents into it.
2. Open a terminal in the project and launch `claude`.
3. Start in Plan Mode and ask Claude to read CLAUDE.md plus docs/PRODUCT.md, docs/DESIGN_SYSTEM.md, docs/ARCHITECTURE.md and docs/ROADMAP.md.
4. Ask: "Before implementing the backend, create a high-fidelity clickable Alexander OS desktop and mobile UI prototype using explicitly labeled demo data. Follow DESIGN_SYSTEM.md exactly. Present design tradeoffs and request my approval before proceeding to the full application."
5. Review the prototype. Iterate on the aesthetic until it feels right.
6. Approve architecture decisions, then implement Stage 1 in small tested tasks.

These documents are a starter specification, not a generated or functioning application. Adjust requirements before development.
